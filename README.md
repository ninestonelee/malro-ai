# 말로 하는 AI 교실 (가칭) · 고객용 랜딩

60·70대를 위한 체험형 AI 교실 안내·신청 페이지입니다. 운영: 주식회사 챗사피엔스 (02-568-5773).

- 공개 주소: https://ninestonelee.github.io/malro-ai/
- 검색 노출 차단(noindex, robots.txt). 링크를 받은 분만 보도록 공유용으로 씁니다.
- 문구·전화번호·일정·비용은 `app.js` 맨 위 `CONFIG`에서 한 번에 바꿉니다.
- 신청서는 기본적으로 카카오톡·전화·이메일로 이어지며, `CONFIG.googleForm`에 구글폼 주소를 넣으면 구글폼으로 바로 쌓입니다.
- 유입 경로는 링크 뒤에 `?src=alumni`, `?src=flyer`처럼 붙여 구분합니다.
- 그림과 휴대폰 화면 속 결과는 AI로 만든 예시입니다.
